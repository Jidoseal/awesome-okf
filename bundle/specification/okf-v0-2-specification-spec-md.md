# OKF v0.2 Specification (SPEC.md)

The universal, vendor-neutral spec, including conformance criteria and reserved filenames. v0.2 (July 2026) makes provenance (`sources`), trust (`generated` / `verified`), lifecycle (`status` / `stale_after`), and attested computations first-class; it supersedes v0.1's `timestamp` field and body `# Citations` list.
