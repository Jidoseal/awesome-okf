# okf-gem

Ruby harness for a bundle's whole life: an agent skill authors and curates concepts, a CLI and library check them (`validate` for v0.1 conformance, `lint` as a separate non-blocking curation report, ranked `search` for retrieval), and `okf server` / `okf render` publish an interactive graph, live or as one self-contained HTML file. Runs fully locally; `gem install okf` or Docker; [live demo](https://demo.okfgem.com). Apache-2.0.
